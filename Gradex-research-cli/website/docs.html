Install Nexora and run your first optimization loop.

Nexora discovers a measurable target, creates a baseline, runs parallel experiments in isolated git worktrees, and keeps only patches that improve your metric and pass your gates.

Quickstart CLI reference Providers Dashboard Analytics Host plugins

Quickstart

Run these commands in any Python project with git initialized.

pip install nexora nexora install cursor nexora discover "make the parser faster" nexora optimize nexora dashboard

After nexora install, Nexora offers a one-time interactive setup for provider, model, and API key (or skip and use flags). Run nexora configure anytime to update saved settings.

Provider setup

Use CLI flags for a quick start, run nexora configure for interactive setup, or store defaults in ~/.nexora/config.toml.

[llm] provider = "groq" model = "llama-3.3-70b-versatile" api_key = "gsk_..." # Other providers: anthropic, openai, ollama, openrouter

Groq

Recommended free cloud provider. Fast inference and no local setup.

OpenRouter

Try Nexora with free-tier models using one API key. Best for testing discover.

Ollama

Fully local. Run ollama serve and pull a model before starting.

Anthropic

Use Claude models when you need deeper code reasoning.

OpenAI

Use GPT models through the OpenAI-compatible path.

Dashboard

The dashboard gives you trust while the optimizer runs: latest run, experiments, pass rate, score chart, and trace logs.

nexora dashboard # Open http://127.0.0.1:8080
  • Experiment table shows status, score, delta from baseline, and gate result.
  • Score chart plots only passed experiments.
  • Analytics cards show pass rate, improvement, best score, and duration.

Analytics

Use stats and history to inspect run quality, export data, and prove that changes improved real metrics.

nexora stats nexora stats --json run.json --csv run.csv nexora report -o run-report.html nexora history --limit 20
